# 480Academy

Maqueta web para fomentar el aprovechamiento de los vídeos formativos y facilitar el seguimiento docente. Hackado 2026 · Cuatroochenta / Universitat Jaume I · Grupo F.

El bootstrap prepara el desarrollo de la demo del **lunes 30 de noviembre de 2026**. El punto de partida implementable es [TASK-01, catálogo unificado](docs/BACKLOG.md#p0--recorrido-principal).
